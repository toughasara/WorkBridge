Description du poste

Nous recherchons un développeur Full Stack expérimenté pour rejoindre notre équipe dynamique. Vous serez responsable du développement et de la maintenance de nos applications web, en travaillant à la fois sur le front-end et le back-end.

Vos responsabilités incluront :

  • Développer de nouvelles fonctionnalités pour nos applications web
  • Maintenir et améliorer le code existant
  • Collaborer avec les designers et les product managers
  • Participer aux revues de code et aux sessions de pair programming
  • Assurer la qualité du code et la performance des applications

Compétences requises

  • 3+ ans d'expérience en développement web
  • Maîtrise de JavaScript, HTML, CSS
  • Expérience avec React et Node.js
  • Connaissance des bases de données MongoDB
  • Expérience avec Git et les méthodologies agiles
  • Bonnes compétences en communication et en travail d'équipe
